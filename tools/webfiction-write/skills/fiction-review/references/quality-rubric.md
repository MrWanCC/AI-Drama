# 通用网文审查基准

- 卖点：本章是否围绕明确卖点推进，而不是只解释背景。
- 冲突：是否出现阻碍、选择、行动、代价或关系变化。
- 情绪：是否有铺垫、升温、释放或反转，避免整章情绪平直。
- 钩子：结尾是否留下具体问题、动作、物件、台词或即时危险。
- 动机：行为是否符合角色目标、性格、处境和关系压力。
- 一致性：不违背已经写下的设定、时间线和角色属性。
- 对话：有潜台词、信息控制和角色差异，不写成说明书。
- 自然度：让动作、观察和即时反应承载信息，避免总结体和万能结论。
- 格式：段落、引号、标点和章节标题不应妨碍阅读。

只有存在原文证据才输出 finding；建议必须给出可执行的修复方向。
