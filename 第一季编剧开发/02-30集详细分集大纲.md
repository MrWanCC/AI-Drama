## 第一篇 01-05《七日修船》

### 第01集《死局》
- **核心事件**：沈川穿越醒来，军法处置的刀已架在脖子上——三十艘船七日修不完，死。
- **目标情绪**：窒息感 + 求生欲（让观众跟着主角一起喘不上气）。
- **阻力**：死期倒计时 + 对自己身份的一无所知。
- **代价**：一旦失败，命就是代价。
- **时间锚点**：八月中，D-7。
- **爽点**：穿越者第一次用"清单+盘点"反杀混乱——别人看到的是一团乱麻，他看到的是"五个可以拆解的问题"。
- **视角**：沈川（限知，随穿越代入）。
- **本章变化**：身份（从"无名待死"到"接下死局的人"）。
- **章末钩子**：账目对不上——这个洞，可能藏着别人的命。
- **节拍节点**：CBN(发现死局) → CPN(盘点乱象) → CPN(看出管理问题) → CEN(账目有洞)。
- **本章禁区**：不写穿越过程啰嗦；不写主角立刻胸有成竹；不出现任何历史名人（保持"小人物"压迫感）。

### 第02集《烂摊子》
- **核心事件**：沈川查清船坊五大困境——木料乱、零件不统一、工序互等、调度乱、账目漏洞。
- **目标情绪**：越看越糟的焦虑，但主角的冷静反而让观众"安下心来看他怎么办"。
- **阻力**：顾承（首次登场）冷眼旁观，等着沈川摔死；有人要借烂船让他顶罪。
- **代价**：沈川意识到，这不止是修船，是有人设的局。
- **时间锚点**：D-6。
- **爽点**：沈川把五大问题拆成一张"问题清单"，第一次让工匠们听懂"你们到底卡在哪"——混乱第一次被"看见"。
- **视角**：沈川。
- **本章变化**：情报（掌握船坊真相 + 发现有人设局）。
- **章末钩子**：木料被谁卡着？顾承笑得意味深长。
- **节拍节点**：CBN(账目对不上) → CPN(逐项查清五大困境) → CPN(发现这是人为设局) → CEN(顾承的冷笑)。
- **本章禁区**：不把顾承写成明显恶人；不让沈川"一眼看穿全局"——让他靠笨办法逐项查。

### 第03集《第一刀》
- **核心事件**：沈川第一次动真格——把"修一艘船"拆成标准工序，推流水作业。
- **目标情绪**：扬眉吐气的"见效快"（前两集憋屈后的第一次释放）。
- **阻力**：老工匠集体抵制"嘴上没毛"的小吏；传统手艺 vs 标准化。
- **代价**：若推不动，七日之期过半，前功尽弃。
- **时间锚点**：D-5~D-4。
- **爽点**：不硬顶，先用"最容易见效的一道工序"示范——第一道工序提速肉眼可见，老工匠从"不信"到"将信将疑"。
- **视角**：沈川。
- **本章变化**：资源（初步获得几名工匠的配合）。
- **章末钩子**：有人把沈川的新法子报给了上面——是福是祸？
- **节拍节点**：CBN(老工匠集体抵制) → CPN(选最易见效工序示范) → CPN(提速肉眼可见) → CEN(新法子被报上去)。
- **本章禁区**：不让老工匠"瞬间折服"——保留"将信将疑"的真实感；不写沈川凭口才说服，靠"做给你看"。

### 第04集《标准与账目》
- **核心事件**：统一零件标准解决返工，同时补上账目漏洞（否则前功尽弃）。
- **目标情绪**：第一次权谋交锋的紧张 + 反将一军的爽。
- **阻力**：补账 = 动别人蛋糕，顾承的人开始使绊子。
- **代价**：若账目漏洞被引爆，沈川会替人顶罪。
- **时间锚点**：D-3~D-2。
- **爽点**：沈川用"标准件+测量"解决返工，用"透明账目"反将一军——让漏洞在阳光下无处遁形。
- **视角**：沈川。
- **本章变化**：关系（顾承从"看戏"转"警觉"，两人正式结梁子）。
- **章末钩子**：第六日，船还差得多——时间不够了。
- **节拍节点**：CBN(返工咬人) → CPN(标准件+测量破返工) → CPN(透明账目反将一军) → CEN(时间不够了)。
- **本章禁区**：不把顾承写蠢；不让沈川的权谋"秒杀"对手——赢得险。

### 第05集《三十一艘》（第一次高潮）
- **核心事件**：第七日最后关头，把船全部推下水。
- **目标情绪**：极限冲刺的热血 + 翻盘的大爽。
- **阻力**：工期极限 + 有人最后一刻使坏（卡最后一批木料）。
- **代价**：差一艘，前六日全废，军法处置。
- **时间锚点**：D-0。
- **爽点**：沈川启动应急预案——提前备好的余量、早已调度的替补工匠、甚至亲手补位。要求三十艘，实际下水**三十一艘**（多出的一艘是"留余量"思维的胜利）。
- **视角**：沈川（高潮段可切周瑜视角一笔带过）。
- **本章变化**：胜负（死局翻盘，全剧第一次大爽点）。
- **章末钩子**：周瑜下令——"把那个沈川带来。"
- **节拍节点**：CBN(最后一刻木料被卡) → CPN(启动应急预案) → CPN(亲手补位) → CEN(三十一艘下水+周瑜点名)。
- **本章禁区**：不靠"神兵天降"翻盘；不写周瑜提前关注沈川（保持"突然被注意到"的冲击力）。

## 第二篇 06-10《周瑜试锋》

### 第06集《初见周瑜》
- **核心事件**：沈川第一次站到周瑜面前，以为凭现代知识能惊艳全场。
- **目标情绪**：被碾压的震撼（反爽点，为互补蓄力）。
- **阻力**：周瑜的顶级智力。
- **代价**：沈川第一次意识到自己"引以为傲的现代知识"在真正的天才面前不够看。
- **时间锚点**：八月末。
- **爽点**：沈川被周瑜三言两语看穿表层心思，第一次意识到"历史人物不是电视剧NPC"——观众同步被震到（这不是爽，是"高级的爽"，认知冲击）。
- **视角**：沈川。
- **本章变化**：关系（周瑜从"这是谁"到"有点意思"）。
- **章末钩子**：周瑜抛出一个问题——"若曹军百万南下，你当如何？"
- **节拍节点**：CBN(沈川自信登场) → CPN(周瑜看穿其心思) → CPN(沈川认知被冲击) → CEN(周瑜抛出军事之问)。
- **本章禁区**：绝不让周瑜降智；不让周瑜"被沈川折服"——这一集沈川必须"输"。

### 第07集《答周瑜》
- **核心事件**：沈川回答周瑜的军事之问。
- **目标情绪**：刀尖上的紧张 + 另辟蹊径的聪明。
- **阻力**：沈川毫无军事经验，答错即欺世盗名。
- **代价**：答不好，前面所有积累归零。
- **时间锚点**：八月末。
- **爽点**：沈川不答"怎么打赢"，答"怎么不输"——把军事问题转成他擅长的"资源与后勤问题"，周瑜第一次"没有完全听懂"，两人第一次产生互补。
- **视角**：沈川。
- **本章变化**：情报（沈川摸到了周瑜的思维方式）。
- **章末钩子**：周瑜说："你这样的人，不该只修船。"
- **节拍节点**：CBN(问题架在火上) → CPN(转换问题视角) → CPN(从"打赢"到"不输") → CEN(周瑜"不该只修船")。
- **本章禁区**：不让沈川说出超越时代的军事预言；他的回答必须"现代工程思维"，而非"历史答案"。

### 第08集《都督府的考察》
- **核心事件**：周瑜暗中设局考察沈川（真才实学/野心/底线），沈川浑然不觉。
- **目标情绪**：上帝视角的"看主角被面试"的趣味 + 沈川踩雷的紧张。
- **阻力**：沈川的现代人"平等观"在江东体系里频频踩雷。
- **代价**：一次踩雷可能前功尽弃。
- **时间锚点**：九月初。
- **爽点**：观众以上帝视角看周瑜如何"面试"主角，沈川靠"做实事、不站队、敢担责"一点点过关。
- **视角**：沈川（穿插周瑜视角）。
- **本章变化**：关系（周瑜从"有点意思"到"再试一次"）。
- **章末钩子**：周瑜递给沈川一项"真实的军事任务"。
- **节拍节点**：CBN(周瑜设局) → CPN(沈川踩雷) → CPN(靠做实事过关) → CEN(真实军事任务)。
- **本章禁区**：不让沈川"看穿"周瑜的考察——他必须"浑然不觉"，才显周瑜的高明。

### 第09集《真实的军事任务》
- **核心事件**：沈川第一次碰"兵"——完成一项看似不起眼、实则凶险的军务（军资押运/前哨补给）。
- **目标情绪**：第一次离开舒适区的忐忑 + 用工程思维办事的巧妙。
- **阻力**：沈川的纸上谈兵第一次撞上现实。
- **代价**：任务失败，周瑜的信任清零。
- **时间锚点**：九月初。
- **爽点**：沈川把"押运"拆成"路线+节点+冗余"，用非军事的方法第一次办成一件军事的事。
- **视角**：沈川。
- **本章变化**：身份（从"船坊小吏"向"都督府可用之人"过渡）。
- **章末钩子**：任务成功，但沈川看到了不该看到的东西。
- **节拍节点**：CBN(接任务) → CPN(纸上谈兵撞现实) → CPN(路线+节点+冗余) → CEN(看到不该看的)。
- **本章禁区**：不让沈川"天生会打仗"；他的优势必须是"工程/组织"，不是"军事天赋"。

### 第10集《百人调度权》（第二次高潮）
- **核心事件**：周瑜把一百人的调度权交到沈川手里。
- **目标情绪**：身份质变的激动 + 立威的爽。
- **阻力**：一百个兵不服一个修船的小吏。
- **代价**：带不动这一百人，就永远只是"修船的"。
- **时间锚点**：九月初。
- **爽点**：沈川用"纪律+分工+明确赏罚"快速立威，而非靠武力或空谈——第一次真正掌兵，身份质变。
- **视角**：沈川。
- **本章变化**：资源（从无人可用，到独领百人）。
- **章末钩子**：周瑜意味深长——"接下来，你要见的不是船，是血。"
- **节拍节点**：CBN(百人调度权) → CPN(士卒不服) → CPN(纪律+分工+赏罚立威) → CEN(周瑜"你要见的是血")。
- **本章禁区**：不靠"武力碾压"立威；不把一百个兵写成无脑龙套。

## 第三篇 11-15《初掌兵权》

### 第11集《初入战场》
- **核心事件**：沈川第一次真正进入战争。
- **目标情绪**：战争的窒息 + 主角被打蒙的反高潮。
- **阻力**：战争的无序、血腥、信息混乱。
- **代价**：第一次真正面对死人。
- **时间锚点**：九月中。
- **爽点**：反高潮设计——观众期待主角发威，结果主角第一次被现实打蒙（这是"成长的爽"的起点）。
- **视角**：沈川。
- **本章变化**：胜负（第一次行动失败或接近失败）。
- **章末钩子**：沈川跪在尸体旁，第一次明白"知道结果≠会打仗"。
- **节拍节点**：CBN(进入战场) → CPN(战争无序血腥) → CPN(第一次失败) → CEN(跪在尸体旁顿悟)。
- **本章禁区**：不美化战争；不让沈川"灵机一动"反败为胜——这一集必须"输"。

### 第12集《失败的学费》
- **核心事件**：失败后复盘，找到"自己的打法"。
- **目标情绪**：低谷中的清醒 + 认知升级的爽。
- **阻力**：军中对"书生掌兵"的嘲讽与不信任。
- **代价**：若不复盘到位，下次就是真死。
- **时间锚点**：九月中。
- **爽点**：沈川把失败拆成系统问题——纪律、情报、地形、工程、组织，逐个补齐，完成"认知升级"。
- **视角**：沈川。
- **本章变化**：情报（第一次掌握真实战场情报）。
- **章末钩子**：沈川发现，敌方的破绽，恰好是他最擅长的地方。
- **节拍节点**：CBN(面对问责) → CPN(复盘失败) → CPN(拆成五要素) → CEN(发现敌方破绽=自己长处)。
- **本章禁区**：不让复盘"一步到位"，保留"还不确定"的紧张。

### 第13集《以己之长》
- **核心事件**：沈川决定不跟名将比"用兵"，比"工程与组织"。
- **目标情绪**：扬长避短的聪明 + 小胜的爽。
- **阻力**：军方旧将反对"不务正业"的打法。
- **代价**：赌上仅剩的信任，换一条非常规路。
- **时间锚点**：九月中。
- **爽点**：用一个"小规模、快见效"的工程胜利，证明这条路走得通——第一次"以弱胜强"的雏形，不靠武力，靠组织。
- **视角**：沈川。
- **本章变化**：资源（获得一支愿意听他的小队）。
- **章末钩子**：更大的敌人来了，这次是真刀真枪。
- **节拍节点**：CBN(决定扬长避短) → CPN(旧将反对) → CPN(小规模工程胜利) → CEN(更大的敌人来了)。
- **本章禁区**：不让沈川"脱离战场"只做后勤——他必须身在一线。

### 第14集《第一次真正的胜利》
- **核心事件**：沈川用"纪律+情报+地形+工程+组织"打一场硬仗。
- **目标情绪**：全剧第二次大爽的热血。
- **阻力**：兵力劣势、时间劣势、内部怀疑。
- **代价**：输了，就是死。
- **时间锚点**：九月中。
- **爽点**：五样武器（纪律/情报/地形/工程/组织）第一次全部用上，一个"不会打仗的人"打赢了。
- **视角**：沈川。
- **本章变化**：胜负（第一次军事胜利）。
- **章末钩子**：捷报北上，一个名字第一次被写进奏报。
- **节拍节点**：CBN(硬仗) → CPN(五样武器全用) → CPN(以弱胜强) → CEN(捷报北上)。
- **本章禁区**：不靠"神级运筹"碾压；胜利必须来自"组织力"，而非"天才用兵"。

### 第15集《名动江东》（第三次高潮）
- **核心事件**：胜利消息层层上报，功劳在江东体系里"变现"。
- **目标情绪**：名动江东的爽 + 隐忧。
- **阻力**：功劳被争抢、稀释、质疑。
- **代价**：若处理不当，赢了也白赢。
- **时间锚点**：九月下。
- **爽点**：沈川不争功，让功劳自己说话——消息第一次传到孙权耳中，孙权第一次记住：沈川。
- **视角**：沈川 + 孙权（一笔）。
- **本章变化**：关系（孙权从"不知道此人"到"听过名字"）。
- **章末钩子**：同时，士族集团也记住了这个名字——他们决定动手。
- **节拍节点**：CBN(功劳被抢) → CPN(不争功) → CPN(功劳传到孙权耳中) → CEN(士族也记住了他)。
- **本章禁区**：不让孙权"就此欣赏"沈川——孙权只是"记住"，多疑仍在。

## 第四篇 16-20《江东暗流》

### 第16集《软刀子》
- **核心事件**：士族集团下场，不杀沈川，让他"什么都做不成"。
- **目标情绪**：有力使不出的憋屈（蓄力）。
- **阻力**：卡粮、卡人、卡船、卡任命、卡资源的阳谋软刀子。
- **代价**：沈川第一次感到"技术能力"在"规则"面前失灵。
- **时间锚点**：九月下。
- **爽点**：反高潮——观众跟着沈川一起憋屈，为后续爆发蓄力。
- **视角**：沈川。
- **本章变化**：关系（沈川与士族集团正式对立）。
- **章末钩子**：连周瑜的面都见不到了——他被"架"起来了。
- **节拍节点**：CBN(敌人换打法) → CPN(五卡齐下) → CPN(有力使不出) → CEN(被架空)。
- **本章禁区**：不写连续几集坐聊；必须有硬冲突（资源被卡是实质变化）。

### 第17集《断粮》
- **核心事件**：粮断了，一百号人等着吃饭。
- **目标情绪**：生存压迫 + 现代供应链思维的爽。
- **阻力**：士族把路一条条堵死。
- **代价**：养不活队伍，人心就散。
- **时间锚点**：十月上。
- **爽点**：沈川用"成本意识+调度"自谋生路，硬是"无中生有"搞到粮。
- **视角**：沈川。
- **本章变化**：资源（从依赖官方，到自建补给）。
- **章末钩子**：搞到粮的方式，埋下了政治隐患。
- **节拍节点**：CBN(断粮) → CPN(路被堵死) → CPN(供应链自谋生路) → CEN(埋下政治隐患)。
- **本章禁区**：不让沈川"凭空变出粮"——他的搞粮方式必须真实、且带代价。

### 第18集《政治的门》
- **核心事件**：沈川从解决技术问题，转向学习江东的政治规则。
- **目标情绪**：成长的顿悟 + 第一次玩政治小胜。
- **阻力**：现代人"平等观"与士族"门第观"正面碰撞。
- **代价**：学会政治，也意味着失去一部分纯粹。
- **时间锚点**：十月上。
- **爽点**：沈川学会"借势"——借周瑜的势、借军功的势、借寒门的势，第一次玩政治并小胜一局。
- **视角**：沈川。
- **本章变化**：情报（摸清江东权力格局）。
- **章末钩子**：他意识到，鲁肃一直在暗中看他。
- **节拍节点**：CBN(撞上门第观) → CPN(学会借势) → CPN(第一次政治小胜) → CEN(鲁肃在暗中)。
- **本章禁区**：不把政治写成"勾心斗角"的爽文套路——必须落地到钱/粮/兵/船/官位/人的实利。

### 第19集《鲁肃的试探》
- **核心事件**：鲁肃正面接触沈川，进行不露声色的试探。
- **目标情绪**：高手过招的暗流 + 被识破又获认可的微妙。
- **阻力**：鲁肃的试探不露声色，却步步致命。
- **代价**：答错，鲁肃看轻，路更难走。
- **时间锚点**：十月上。
- **爽点**：沈川第一次展现"战略眼光"——不只看眼前，敢谈长远，鲁肃判断"此人与普通寒门不同"。
- **视角**：沈川。
- **本章变化**：关系（鲁肃从"观察"到"有意保护"）。
- **章末钩子**：鲁肃说了一句让沈川心惊的话——"你似乎在等一场仗。"
- **节拍节点**：CBN(鲁肃正面接触) → CPN(步步试探) → CPN(沈川展战略眼光) → CEN("你似乎在等一场仗")。
- **本章禁区**：绝不让鲁肃"降智"或"被沈川折服"——鲁肃必须始终高沈川一截。

### 第20集《孙权召见》（第四次高潮）
- **核心事件**：孙权第一次正式召见沈川。
- **目标情绪**：见君主的紧张 + 底层逆袭的爽。
- **阻力**：孙权多疑，沈川每句话都在被"帝王心术"审视。
- **代价**：一句话说错，万劫不复。
- **时间锚点**：十月上。
- **爽点**：沈川不谄媚、不夸大、不藏拙，用"诚实+有用"通过孙权第一道筛选——底层小吏站到江东最高统治者面前。
- **视角**：沈川 + 孙权。
- **本章变化**：身份（被孙权记住，进入更高视野）。
- **章末钩子**：就在这时，八百里加急——曹操，南下了。
- **节拍节点**：CBN(被召见) → CPN(帝王心术审视) → CPN(诚实+有用过关) → CEN(曹操南下加急)。
- **本章禁区**：不让孙权"就此信任"沈川；孙权的"召见"是试探+立威+借刀。

## 第五篇 21-25《曹操南下》

### 第21集《曹操南下》
- **核心事件**：曹操大军南征，荆州告急，个人恩怨被"江东存亡"碾压。
- **目标情绪**：格局骤升的震撼。
- **阻力**：时代巨变的冲击。
- **代价**：沈川意识到之前斗的一切，在"亡国"面前都不值一提。
- **时间锚点**：十月（曹操起兵南征，史实）。
- **爽点**：格局骤升——从"内部竞争"跳到"天下大势"，沈川第一次跳出小格局看大棋。
- **视角**：沈川。
- **本章变化**：情报（天下格局突变）。
- **章末钩子**：刘表病重，荆州风雨飘摇。
- **节拍节点**：CBN(曹军南征) → CPN(个人恩怨被碾压) → CPN(格局骤升) → CEN(刘表病重)。
- **本章禁区**：不把"曹操南下"写成突然惊吓——它是渐进的、可预见的时代压力。

### 第22集《荆州易主》
- **核心事件**：刘表病逝、刘琮降曹、荆州尽归曹操。
- **目标情绪**：历史与现实同步的震撼 + 主角的复杂心境。
- **阻力**：沈川发现自己"知道的历史"正走向记忆中的结局，既安心又恐惧。
- **代价**：沈川第一次认真思考"我到底能改变什么"。
- **时间锚点**：八~九月（刘表病逝、刘琮降曹，史实）。
- **爽点**：观众看到主角历史记忆与现实同步，代入感拉满（"主角早知道"的爽感）。
- **视角**：沈川。
- **本章变化**：情报（荆州易主真相）。
- **章末钩子**：曹军前锋，已经逼近江东。
- **节拍节点**：CBN(刘表病逝) → CPN(刘琮降曹) → CPN(沈川的安心与恐惧) → CEN(曹军逼近)。
- **本章禁区**：不写沈川"幸灾乐祸"或"指点江山"——他必须真实地恐惧。

### 第23集《压境》
- **核心事件**：曹军压境，江东人心惶惶，主战主降开始撕裂。
- **目标情绪**：山雨欲来的压抑 + 主角亮判断的爽。
- **阻力**：主降派的"曹操势大"论。
- **代价**：沈川若判断错，会误导整个主战派。
- **时间锚点**：十月中。
- **爽点**：沈川用"数据+逻辑"在内部发声——曹操的军力没有想象中可怕。
- **视角**：沈川。
- **本章变化**：关系（进入主战派视野）。
- **章末钩子**：但有一个"他记忆中本该发生的事"，迟迟没有发生。
- **节拍节点**：CBN(曹军压境) → CPN(主战主降撕裂) → CPN(沈川亮数据判断) → CEN(本该发生的事没发生)。
- **本章禁区**：不让沈川"算无遗策"——他的判断要有逻辑支撑，但也要为"历史偏移"留伏笔。

### 第24集《历史的裂缝》
- **核心事件**：沈川发现一个记忆中"本该发生"的事件，没有按原历史发生。
- **目标情绪**：金手指失灵的巨大恐惧。
- **阻力**：一直以来最大的外挂（历史记忆）第一次失灵。
- **代价**：如果历史是错的，沈川的"预知"优势归零。
- **时间锚点**：十月中。
- **爽点**：反爽点设计——主角失去"预知"安全感，为下一集认知升级蓄力（这是"深层的爽"）。
- **视角**：沈川。
- **本章变化**：情报（历史偏移的真相）。
- **章末钩子**：他做了一个决定——从今以后，记忆只作参考，不作答案。
- **节拍节点**：CBN(事件没发生) → CPN(恐惧) → CPN(外挂失灵) → CEN(决定记忆只作参考)。
- **本章禁区**：不写沈川"崩溃失态"过度；恐惧要真实但克制。

### 第25集《历史不是剧本》（第五次高潮）
- **核心事件**：沈川完成认知蜕变——把历史记忆从答案降级为参考。
- **目标情绪**：失去依赖后重新站起来的成长爽。
- **阻力**：失去"预知"安全感的恐惧 vs 重新站起来的勇气。
- **代价**：承认"我靠的不是答案，是能力"。
- **时间锚点**：十月中。
- **爽点**：主角失去金手指式的安全感，却因此变得更真实、更强——他真正强的地方，从来不是"知道答案"，而是"能拆问题"。
- **视角**：沈川。
- **本章变化**：身份（从"依赖预知的人"到"真正独立的人"）。
- **章末钩子**：主战主降之争，在朝堂彻底爆发。
- **节拍节点**：CBN(失去安全感) → CPN(重新审视自己) → CPN(想通"能拆问题"才是强) → CEN(朝堂之争爆发)。
- **本章禁区**：不把这次成长写成"顿悟一瞬间"——要有挣扎、有反复。

## 第六篇 26-30《赤壁前夜》

### 第26集《朝堂之争》
- **核心事件**：主战派与主降派正面交锋。
- **目标情绪**：存亡之争的紧张 + 主角站出来的爽。
- **阻力**：主降派的"曹操势大"论。
- **代价**：立场错了，就是死路。
- **时间锚点**：十一下。
- **爽点**：沈川用"工程+后勤+数据"的视角，为主战派提供"可守"的技术底气，现代思维第一次在"国策"层面被认可。
- **视角**：沈川。
- **本章变化**：关系（成为主战派关键助力）。
- **章末钩子**：周瑜回归，局势为之一变。
- **节拍节点**：CBN(朝堂交锋) → CPN(主降派压人) → CPN(沈川提供"可守"底气) → CEN(周瑜回归)。
- **本章禁区**：不把主降派写成蠢货——他们"降"有降的现实逻辑。

### 第27集《周瑜归来》
- **核心事件**：周瑜回归，主战派有了主心骨，两人互补成形。
- **目标情绪**：强强联合的爽。
- **阻力**：周瑜的统帅之才与沈川的组织之才需要磨合。
- **代价**：磨合不好，抗曹大计难成。
- **时间锚点**：十一月（周瑜回归，史实）。
- **爽点**：沈川主动补位——周瑜管"怎么打"，沈川管"怎么把仗打得起"，两人互补关系彻底成形。
- **视角**：沈川 + 周瑜。
- **本章变化**：关系（周瑜与沈川从"用"到"真正倚重"）。
- **章末钩子**：孙权决意抗曹，但需要一个"说得过去的理由"。
- **节拍节点**：CBN(周瑜回归) → CPN(两才磨合) → CPN(互补成形) → CEN(孙权需要理由)。
- **本章禁区**：不把沈川抬到"与周瑜并列"——沈川是"补位"，周瑜是"统帅"。

### 第28集《鲁肃奔走》
- **核心事件**：鲁肃奔走于孙刘之间，联刘抗曹大计成形，沈川参与顶层设计。
- **目标情绪**：参与天下棋局的爽。
- **阻力**：孙刘联盟内部信任与猜忌并存。
- **代价**：联盟若不成，江东孤军。
- **时间锚点**：十一月（孙刘联盟，史实）。
- **爽点**：沈川用"战略眼光"帮鲁肃补上联盟中的一块拼图，第一次参与"天下棋局"的顶层设计。
- **视角**：沈川 + 鲁肃。
- **本章变化**：情报（孙刘联盟内幕）。
- **章末钩子**：曹操大军，终于到了江对岸。
- **节拍节点**：CBN(鲁肃奔走) → CPN(联盟内猜忌) → CPN(沈川补拼图) → CEN(曹军到江对岸)。
- **本章禁区**：不把"联刘抗曹"写成沈川的功劳——它是鲁肃、周瑜、孙权共同的历史决策。

### 第29集《剑拔弩张》
- **核心事件**：孙刘联军与曹军隔江对峙，大战一触即发，沈川做最后的组织准备。
- **目标情绪**：大战前夜的紧绷 + 组织力巅峰的爽。
- **阻力**：战前动员、后勤、水军整备千头万绪，时间紧迫。
- **代价**：备战不力，开战即溃。
- **时间锚点**：十一月。
- **爽点**：沈川用"标准化+调度"把混乱的备战变成井井有条，组织能力在"大战前夜"达到第一季顶峰。
- **视角**：沈川。
- **本章变化**：资源（获得战前整备的实权）。
- **章末钩子**：一封密信送到孙权案头——有人主张投降。
- **节拍节点**：CBN(隔江对峙) → CPN(备战千头万绪) → CPN(标准化调度整备) → CEN(有人主张投降的密信)。
- **本章禁区**：不写大规模战争全景（遵守AI制作约束）；用"准备"而非"开战"体现张力。

### 第30集《赤壁前夜》（第六次高潮·季终）
- **核心事件**：孙权召开最高军议，沈川以最末位入席，说出改变江东命运的一句话。
- **目标情绪**：全季最大的爽 + 意犹未尽的悬念。
- **阻力**：群臣争论曹操"八十万大军"，主降派气势汹汹。
- **代价**：一句话说错，就是死。
- **时间锚点**：十一月，赤壁前夜。
- **爽点**：最末位的小吏走到地图前，用"数据+逻辑"拆穿八十万的虚妄——全剧最大爽点。
- **视角**：沈川（收束到孙权点名）。
- **本章变化**：身份（从"最末位"到"被孙权点名的人"）。
- **章末钩子**：孙权："沈川，你来说。" 沈川："曹操没有八十万大军。"——黑屏。
- **节拍节点**：CBN(最末位入席) → CPN(群臣争论八十万) → CPN(沈川走到地图前) → CEN(说出那句话+黑屏)。
- **本章禁区**：不拍赤壁大战；不让沈川"技惊四座"到夸张——他仍是资历最浅的人，只是"有资格开口"。
