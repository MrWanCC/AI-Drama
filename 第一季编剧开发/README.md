## 核心设定遵守情况（对照圣经）

- ✅ 爽感60% / 战争20% / 权谋15% / 氛围5%
- ✅ 无系统、无商城、无无限仓库、无签到
- ✅ 历史名人（周瑜/鲁肃/孙权/曹操）不降智
- ✅ 主角不凭空掌握专业知识（只懂工程管理，不懂造船手艺）
- ✅ 每5集一个高潮（05/10/15/20/25/30）
- ✅ 每集至少一种变化（身份/资源/关系/情报/胜负）
- ✅ 禁止连续两集只有铺垫（11-12、16-17均为高压+硬冲突）
- ✅ 前3集极强、第5集第一次明显高潮
- ✅ 尽量避开常见三国穿越套路（见03文件附"差异化"自查）
