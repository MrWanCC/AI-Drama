# 《江东潜龙》第一季 · 第1-5集详细展开（七日修船篇）

> 每集约3分钟短剧设计，3-6场戏。
> 本文件不写完整对白，只写：场次、场景、内容、情绪节奏、镜头提示（用于后续AI分镜，本轮不产出分镜）。
> 遵循：前15秒必出冲突；爽感优先但不无脑；前3集极强；第5集第一次明显高潮。

---

## 第01集《死局》（约3分钟 · 5场）

### 开场钩子（前15秒）
> 军法处置的刀，已经架在脖子上了。

**场1｜醒来就是死局**（约40秒）
- 场景：柴桑船坊，破旧的木棚内。
- 内容：沈川从混沌中醒来，头痛欲裂。眼前是陌生的古代船坊，耳边是监工催促的呵斥。他还没搞清楚自己是谁，就被告知：**三十艘战船，七日内修复，逾期军法处置**。
- 情绪：窒息 + 求生欲。
- 镜头提示：第一人称式的慌乱，快速扫过环境，最后定格在"七日"两个字上（木牌/口谕）。

**场2｜身份拼图**（约35秒）
- 场景：木棚内，沈川翻找"这具身体"的随身之物。
- 内容：通过零散物件（账册、工牌、半张名帖）拼出身份——一个负责木料、工匠、修船进度和账目登记的底层小吏。没有人脉，没有靠山。
- 情绪：越看越绝望。
- 镜头提示：物件特写，逐件揭示，节奏克制。

**场3｜第一个现代反应**（约40秒）
- 场景：船坊内，沈川强压慌乱，开始盘问工匠、点数船只。
- 内容：沈川用现代人的习惯——不慌着动手，先"盘点"。他问清：多少船、多少工匠、多少木料、几天可用。工匠们面面相觑：这小吏疯了？不想活还问东问西。
- 情绪：紧张中透出一丝"主角有办法"的暗示。
- 镜头提示：沈川问问题时的冷静，与工匠的不解形成反差。

**场4｜发现"人不是问题"**（约40秒）
- 场景：船坊内，沈川站在船堆前。
- 内容：盘点完成。沈川得出第一个判断：**修不完，不是因为人少，而是因为管理混乱**——木料乱、零件不统一、工序互相等待、调度混乱。他第一次用现代眼光，把这个死局"看穿"了。
- 情绪：压抑中透出转机。
- 爽点：别人看到一团乱麻，他看到了五个可以拆解的问题。
- 镜头提示：主观镜头在混乱的船坊里，逐一定格五大问题。

**场5｜账目有洞**（约30秒 · 追更钩子）
- 场景：木棚内，油灯下。
- 内容：沈川翻着账册，突然手一顿——账目对不上。有一笔木料，去向不明。他皱眉：这不止是修船，这账里有别人的命。
- 情绪：新的悬念压来。
- 追更钩子：这个洞，可能藏着别人的命。

**本集节奏校验**：钩子(15s) → 身份(35s) → 反应(40s) → 破局(40s) → 钩子(30s)。身份变化：从"无名待死"到"接下死局"。

## 第02集《烂摊子》（约3分钟 · 5场）

### 开场钩子（前15秒）
> 有人要借这艘烂船，让他顶罪。

**场1｜账目对不上**（约35秒）
- 场景：木棚内，沈川反复核对账册。
- 内容：沈川确认账目有漏洞——一笔木料被记了假账。他意识到：这船坊本身就是个烂摊子，而有人正等着一个"替罪羊"。
- 情绪：警觉。
- 镜头提示：账册特写，数字对不上。

**场2｜顾承登场**（约40秒）
- 场景：船坊主事厅，沈川第一次见顾承。
- 内容：顾承是船坊主事之一，态度和善，话里有话。他"好心"提醒沈川：期限快到了，别折腾。沈川从顾承的笑意里，读到"等你摔死"。
- 情绪：绵里藏针的暗流。
- 人物：顾承（38岁左右，江东豪族旁支，非脸谱化反派——他是"体系守门人"）。
- 镜头提示：顾承的从容与沈川的警惕对比。

**场3｜逐项查清五大困境**（约45秒）
- 场景：船坊各处（木料场、工棚、码头）。
- 内容：沈川不用"聪明"，用"笨办法"——逐项查。他查清五大问题：木料乱（堆放无账）、零件不统一（各船各的尺寸）、工序互相等待（甲等乙，乙等丙）、工匠调度混乱（闲的闲死忙的忙死）、账目漏洞（有人做假账）。
- 情绪：越查越糟，但沈川越查越冷静。
- 镜头提示：蒙太奇，五个问题各给一个画面。

**场4｜第一次"讲给工匠听"**（约40秒）
- 场景：工棚，沈川把工匠叫到一起。
- 内容：沈川把五大问题拆成一张"问题清单"，用最直白的话讲给工匠听——"你们不是修不完，是卡在了这里、这里、这里。"工匠们第一次听懂了"自己到底卡在哪"。
- 情绪：混乱第一次被"看见"的畅快。
- 爽点：主角把一团乱麻，拆成了人人能懂的清单。
- 镜头提示：工匠们从"不听"到"若有所思"。

**场5｜木料被谁卡着**（约30秒 · 追更钩子）
- 场景：木料场，沈川发现木料短缺的关键。
- 内容：沈川追到木料来源——被卡住了。他回头，顾承在远处，笑得意味深长。
- 情绪：危机升级。
- 追更钩子：木料被谁卡着？

**本集节奏校验**：钩子(15s) → 查账(35s) → 顾承(40s) → 查困境(45s) → 讲清单(40s) → 钩子(30s)。情报变化：掌握船坊真相 + 发现有人设局。

## 第03集《第一刀》（约3分钟 · 5场）

### 开场钩子（前15秒）
> 老工匠当场甩手："嘴上没毛，修什么船！"

**场1｜老工匠抵制**（约40秒）
- 场景：工棚，沈川宣布要改"工序"。
- 内容：沈川提出"工序拆分+流水作业"，老工匠们当场炸了——"我们修了几十年的船，轮的着你个小吏指手画脚？"传统手艺 vs 标准化，正面碰撞。
- 情绪：冲突拉满。
- 镜头提示：老工匠拍案，沈川被围住。

**场2｜不硬顶，选最易见效的**（约35秒）
- 场景：工棚，沈川冷静退让一步。
- 内容：沈川不硬顶，也不讲大道理。他挑出"最容易见效的一道工序"（如统一打磨/统一拼接），说："别的先不动，就这一道，听我一天。"
- 情绪：以退为进的聪明。
- 镜头提示：沈川用手指在木头上画出工序。

**场3｜示范提速（爽点）**（约45秒）
- 场景：工棚，一道工序的示范。
- 内容：沈川亲手示范"标准工序"——原本各干各的，现在流水线式分工。第一道工序的提速**肉眼可见**。老工匠们从"不信"到"将信将疑"，有人不自觉地跟着做。
- 情绪：扬眉吐气。
- 爽点：不靠口才，靠"做给你看"。
- 镜头提示：对比镜头，改造前 vs 改造后的速度差。

**场4｜将信将疑的松动**（约35秒）
- 场景：工棚，收工后。
- 内容：几个工匠私下嘀咕——"这小子，好像真有点门道。"但老资格的仍不服："一天看不出啥。"沈川不解释，只说明天继续。
- 情绪：暗流中的松动。
- 镜头提示：工匠们的表情变化。

**场5｜新法子被报上去**（约30秒 · 追更钩子）
- 场景：船坊外，一个小吏模样的人匆匆离开。
- 内容：有人把沈川的"新法子"报给了上面。沈川看着那人的背影，意识到自己的每一步都在被盯着。
- 情绪：悬疑。
- 追更钩子：是福是祸？

**本集节奏校验**：钩子(15s) → 抵制(40s) → 退让(35s) → 示范(45s) → 松动(35s) → 钩子(30s)。资源变化：初步获得几名工匠的配合。

## 第04集《标准与账目》（约3分钟 · 5场）

### 开场钩子（前15秒）
> 零件不统一，一艘船返工了三遍。

**场1｜返工咬人**（约35秒）
- 场景：码头，一艘船反复返工。
- 内容：零件尺寸不统一，这艘船的部件拼不上，返工了三遍，工期被白白吃掉。沈川明白：不统一标准，前面全白干。
- 情绪：焦虑。
- 镜头提示：拼不上的零件特写。

**场2｜标准件+测量破返工**（约45秒）
- 场景：工棚，沈川推行"统一标准"。
- 内容：沈川用"标准件+测量"——所有部件按统一尺寸做，用最原始的测量工具（墨线、定尺）卡尺寸。返工率骤降。
- 情绪：技术的爽。
- 爽点：现代"标准化"第一次在古代船坊立竿见影。
- 镜头提示：测量工具的细节。

**场3｜账目漏洞开始咬人**（约40秒）
- 场景：木棚，账册出问题。
- 内容：顾承的人开始使绊子——把账目漏洞往沈川身上引。沈川意识到：补账 = 动别人蛋糕，但不补，他就会替人顶罪。
- 情绪：两难。
- 镜头提示：账册与顾承手下人的阴笑。

**场4｜透明账目反将一军**（约40秒）
- 场景：主事厅，沈川当众摊账。
- 内容：沈川没有私下补账，而是**把账目当众摊开**——让漏洞在阳光下无处遁形。做假账的人慌了。顾承第一次认真打量沈川。
- 情绪：反将一军的爽。
- 爽点：用"透明"破"暗箱"，现代成本意识第一次在权谋场赢下一回合。
- 镜头提示：众人看账时的表情，顾承的眼神变化。

**场5｜时间不够了**（约25秒 · 追更钩子）
- 场景：船坊，天色渐暗，沈川看着剩下的船。
- 内容：第六日，船还差得多。沈川攥紧拳头：时间不够了。
- 情绪：压力拉满。
- 追更钩子：第六日，时间不够了。

**本集节奏校验**：钩子(15s) → 返工(35s) → 标准(45s) → 账目(40s) → 反将(40s) → 钩子(25s)。关系变化：顾承从"看戏"转"警觉"，两人结梁子。

## 第05集《三十一艘》（约3分30秒 · 6场 · 第一次高潮）

### 开场钩子（前15秒）
> 第七日清晨，工期看似已死。

**场1｜最后一天**（约35秒）
- 场景：船坊，第七日清晨，雾气未散。
- 内容：期限已到，船还差得多。工匠们垂头丧气，有人已经开始收拾东西等死。沈川站在码头，沉默。
- 情绪：绝望的压抑。
- 镜头提示：大全景，未完工的船，低气压。

**场2｜最后一刻使坏**（约40秒）
- 场景：木料场，沈川去领最后一批木料。
- 内容：最后一批木料被卡住了——有人最后关头使坏。沈川盯着空空的木料场，明白这是要让他"差一艘"。
- 情绪：愤怒 + 绝境。
- 镜头提示：空木料场，沈川攥紧的拳头。

**场3｜应急预案启动（转机）**（约40秒）
- 场景：船坊，沈川转身，命令式的调度。
- 内容：沈川没有慌——他早有准备。他启动"应急预案"：提前备好的余量木料、早已说好的替补工匠、连他自己都撸起袖子。这一段的他，像一个真正的指挥者。
- 情绪：绝地反击的热血。
- 爽点：别人以为他输了，其实他留了后手——"留余量"思维的胜利。
- 镜头提示：沈川指挥调度的利落，工匠们被带动。

**场4｜亲手补位（高潮推进）**（约40秒）
- 场景：船坊，最后的冲刺。
- 内容：沈川脱下外衣，亲手加入修船——不是高高在上地指挥，而是和工匠一起扛木头、拼船板。这一刻，工匠们真正服了他。
- 情绪：热血 + 共情。
- 镜头提示：沈川扛木头的背影，工匠们看他的眼神变了。

**场5｜三十一艘下水（最高潮爽点）**（约45秒）
- 场景：码头，船一艘艘下水。
- 内容：要求修复**三十艘**，最终下水**三十一艘**。多出的那一艘，是沈川"留余量"思维的胜利。工匠们欢呼，沈川站在码头，浑身是汗，第一次露出笑。
- 情绪：全剧第一次大爽。
- 爽点：极限翻盘 + 超额完成。
- 镜头提示：三十一艘船下水的壮阔镜头（遵守AI约束，用船阵而非人海）。

**场6｜周瑜点名（追更钩子）**（约25秒）
- 场景：都督府，一封简报递到周瑜案头。
- 内容：周瑜看着简报上的数字，抬起眼，淡淡一句：**"把那个沈川带来。"**
- 情绪：新篇章开启的期待。
- 追更钩子：周瑜点名，沈川的命运迎来转折。

**本集节奏校验**：钩子(15s) → 最后一天(35s) → 使坏(40s) → 应急预案(40s) → 补位(40s) → 下水(45s) → 点名(25s)。胜负变化：死局翻盘，全剧第一次大爽点。

## 附：第1-5集与常见三国穿越套路的差异化

1. **不靠"神兵天降"**：沈川赢，靠的是"留余量+标准化+透明账目"，是管理，不是武力或天降。
2. **不靠"历史答案"**：前5集完全不用"预知"——他解决的是纯工程管理问题，历史知识一点没用上。
3. **不靠"名将折服"**：前5集周瑜、孙权一个都没出场，沈川的对手只是"死局"和"烂摊子"，是"小人物自救"。
4. **顾承不是"恶毒反派"**：他前期只是"冷眼旁观"，不主动害人，是"体系对变革者的天然阻力"。
5. **失败是真实的**：第01集主角慌乱，第02集靠笨办法，第03集只推一道工序，没有一步登天。
