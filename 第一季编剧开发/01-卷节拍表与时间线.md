## 二、六篇卷节拍表

### 第一篇 01-05《七日修船》
- **功能**：开局死局 + 第一个大爽点（铺垫与起步）
- **核心事件**：沈川七日修好三十艘船，实际下水三十一艘
- **起始状态 → 结束状态**：无名待死小吏 → 被周瑜点名的有功小吏
- **中段反转**：第03集老工匠集体抵制"工序拆分"，第04集账目漏洞反咬
- **危机链（3次递进）**：
  1. 死期倒计时（军法处置）→ 2. 木料被卡（资源断供）→ 3. 最后一批木料被使坏（临门一脚受阻）
- **篇末钩子**：周瑜下令"把那个沈川带来"
- **章节定位**：推进（主）+ 高压（次）

### 第二篇 06-10《周瑜试锋》
- **功能**：顶级人物登场 + 认知升级（起步）
- **核心事件**：沈川初见周瑜，被碾压后靠"互补"获得百人调度权
- **起始状态 → 结束状态**：有功小吏 → 独领百人的军中基层
- **中段反转**：沈川以为能惊艳周瑜，结果被三言两语看穿（第06集）
- **危机链（3次递进）**：
  1. 答错周瑜之问就欺世盗名 → 2. 现代人"平等观"频频踩雷 → 3. 百名士卒不服小吏
- **篇末钩子**：周瑜说"接下来你要见的不是船，是血"
- **章节定位**：关系（主）+ 信息（次）

### 第三篇 11-15《初掌兵权》
- **功能**：第一次真正的战争洗礼 + 第二次大爽点（第一个大爽点后的成长）
- **核心事件**：沈川初战失败→见血→用"自己的方式"完成以弱胜强
- **起始状态 → 结束状态**：独领百人的书生 → 名动江东的有功之将
- **中段反转**：第11集反高潮——期待主角发威，主角被打蒙、跪在尸体旁
- **危机链（3次递进）**：
  1. 初战失败（接近死）→ 2. 军中不信任（书生掌兵）→ 3. 更大的真刀真枪之敌
- **篇末钩子**：消息传到孙权耳中，同时士族集团也记住了这个名字
- **章节定位**：推进（主）+ 高压（主）

### 第四篇 16-20《江东暗流》
- **功能**：从技术问题转入政治问题 + 第三次转折（权谋）
- **核心事件**：沈川被士族软刀子架住，学会政治后获孙权召见
- **起始状态 → 结束状态**：有功之将 → 进入孙权视野的可用之人
- **中段反转**：第16集沈川以为立了功就能升，结果被"卡"到有力使不出
- **危机链（3次递进）**：
  1. 被架空（连周瑜面都见不到）→ 2. 断粮（一百号人等着吃饭）→ 3. 政治规则全面围堵
- **篇末钩子**：孙权召见的同时，八百里加急——曹操南下
- **章节定位**：关系（主）+ 呼吸（次，鲁肃线）

### 第五篇 21-25《曹操南下》
- **功能**：格局骤升 + 历史偏移（核心命题转折）
- **核心事件**：曹军压境，历史偏移，沈川认知崩溃后完成蜕变
- **起始状态 → 结束状态**：困于江东内斗的人 → 真正独立、敢于面对天下的人
- **中段反转**：第24集"本该发生的事没发生"，历史记忆第一次失灵
- **危机链（3次递进）**：
  1. 荆州易主（世界变了）→ 2. 曹军压境（江东可能灭亡）→ 3. 历史偏移（外挂失灵）
- **篇末钩子**：主战主降之争在朝堂彻底爆发
- **章节定位**：信息（主）+ 高压（次）

### 第六篇 26-30《赤壁前夜》
- **功能**：全季最高潮 + 季终悬念（收束）
- **核心事件**：沈川进入最高军议，说出"曹操没有八十万大军"
- **起始状态 → 结束状态**：主战派助力 → 被孙权点名的、最末位的军议参与者
- **中段反转**：第29集有人主张投降，密信上达孙权
- **危机链（3次递进）**：
  1. 主降派气势汹汹 → 2. 孙权需要"说得过去的理由" → 3. 曹操大军已到江对岸
- **篇末钩子**：孙权点名沈川，沈川说"曹操没有八十万大军"——黑屏
- **章节定位**：推进（主）+ 高压（主）+ 关系（次）

## 三、节奏校验（对照圣经硬规则）

| 圣经硬规则 | 本季落实情况 |
|---|---|
| 前15秒必出冲突 | 每集钩子均为"问题/冲突/死局"式开场，见逐集总纲 |
| 每集至少一种变化 | 30集全部标注变化类型（身份/资源/关系/情报/胜负） |
| 每5集一个高潮 | 05修船奇迹 / 10百人调度权 / 15军事胜利 / 20孙权召见 / 25历史偏移 / 30最高军议 |
| 禁止连续两集只有铺垫 | 第11-12集（失败+复盘）为"高压"而非纯铺垫；第16-17集（被困+断粮）均带硬冲突 |
| 爽感60% / 战争20% / 权谋15% / 氛围5% | 前15集爽感密集（修船、掌兵、胜利），后15集权谋+战争+认知成长为主，爽感持续 |
